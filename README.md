# Presnotic Bank Demo

Консольное банковское приложение, разработанное на чистой Java.

## О проекте

Проект создан в учебных целях для практического изучения Java Core.

Приложение представляет собой упрощённую банковскую систему, в которой
пользователь может работать со своими счетами и выполнять переводы между ними.

Проект разрабатывается без использования сторонних фреймворков и библиотек —
только стандартные возможности Java.

## Основные возможности

- создание пользователей;
- создание банковских счетов;
- пополнение и снятие средств;
- переводы между счетами;
- просмотр счетов пользователя;
- обработка ошибок и собственные исключения;
- консольный интерфейс;
- многопоточные операции со счетами.

## Архитектура

Проект разделён на несколько основных слоёв:

- `models` — основные сущности приложения;
- `repositories` — хранение и получение данных;
- `services` — бизнес-логика;
- `core` — основная логика приложения и управление системой;
- `ui` — консольный интерфейс и обработка пользовательского ввода;
- `exceptions` — пользовательские исключения;
- `enums` — перечисления.

## Многопоточность

Одной из основных целей проекта является изучение многопоточности в Java
на практическом примере.

В проекте рассматриваются:

- `Thread`;
- `Runnable`;
- `ExecutorService`;
- `synchronized`;
- `AtomicLong`;
- `AtomicReference`;
- race condition;
- потокобезопасная работа с общими ресурсами;
- синхронизация операций со счетами.

Для проверки многопоточности реализованы отдельные тестовые сценарии,
в которых несколько потоков одновременно работают с банковскими счетами.

## Используемые технологии

- Java
- Java Collections
- Stream API
- ExecutorService
- Atomic variables

## Цель проекта

Главная цель проекта — не создание полноценной банковской системы, а
получение практического опыта разработки на Java без использования
фреймворков.
